# Numo

Turn any lecture into a perfect quiz in seconds, no editing needed.

Students join every poll from a browser with a six-digit code.

Results sync straight to Canvas and Moodle.

Works offline, so a bad connection never stops a class.

Numo grades open-ended answers for you, so you can get back to teaching.

Teachers using Numo see 40% more of the room answering, guaranteed.
